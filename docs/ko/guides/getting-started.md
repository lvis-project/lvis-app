# 시작 가이드

상태: 영문 기준 문서의 한국어 미러입니다. 원문은 [../../guides/getting-started.md](../../guides/getting-started.md)이며, 두 문서가 어긋날 때는 영문 원문과 소스 코드가 기준입니다.

## 이 문서가 다루는 범위

이 문서는 깨끗한 체크아웃에서 데스크톱 앱을 실행하고 검사하고 이해하기까지의 경로를 다룹니다. 이 영역을 변경할 때 가장 먼저 확인할 문서로 사용하세요.

## 현재 운영 규약

- 이 앱 표면의 기준 언어는 영어이고, 이 문서는 그 내용을 한국어로 옮긴 미러입니다.
- 문서는 지금도 유효한 동작, 그 동작을 강제하는 코드나 테스트의 위치, 그리고 이 설명이 낡았다고 판단할 조건을 함께 밝혀야 합니다.
- 이 문서의 서술과 구현이 다르면 소스 파일과 테스트가 기준입니다.
- 영문 원문이 바뀌면 이 미러도 같은 커밋에서 함께 갱신합니다.

## 깨끗한 체크아웃에서 실행

```bash
bun install
bun run build
bun run start
```

패키지 매니저는 Bun 이지만 Electron 과 일부 빌드 스크립트는 시스템 `node` CLI 를 직접 호출하므로, 두 실행 파일이 모두 PATH 에 있어야 합니다. Windows 전용 설정은 [Windows 개발 환경](./windows-setup.md)에서 다룹니다.

## 첫 실행: 공급자 연결

공급자를 연결하기 전에는 아무 응답도 받을 수 없으므로, 첫 순서는 **설정 → 모델** 화면입니다.

1. **공급자 추가**를 누릅니다. 새 카드는 추가한 순서대로 그 단추 바로 위에 나타나고, 화면 안으로 스크롤됩니다.
2. 카드에 자격 증명을 입력합니다. **저장 단추는 카드 안에**, 저장 대상 입력란 옆에 있습니다. 저장된 값과 다른 입력이 하나라도 있어야 활성화되며, 입력을 남긴 채 접은 카드는 그 입력을 버리지 않고 저장하지 않음으로 표시합니다.
3. **엔드포인트** 입력란은 엔드포인트를 사용자가 직접 지정하는 경우에만 나타납니다. 범용 OpenAI 호환 공급자, Azure AI Foundry, 그리고 자체 호스팅 계열(Ollama, LM Studio, LiteLLM)이 여기에 해당합니다. 엔드포인트가 고정된 공급자와 마켓플레이스 프리셋으로 설치한 공급자에는 이 입력란이 나타나지 않습니다.
4. OpenAI 행은 한 줄에 세 가지 진입 방법을 제공합니다. **브라우저에서 로그인**, **디바이스 코드 사용**, **API 키 사용**입니다. 마지막 항목을 누르면 카드에 키 입력란이 나타나고, 앞의 두 항목은 메인 프로세스가 열며 로그인 주소나 계정 토큰은 설정 화면으로 전달되지 않습니다.
5. 모델 목록은 앱에 내장된 목록을 읽는 것이 아니라 공급자에서 받아 옵니다. 카드는 그 동기화 상태를 그대로 알립니다. 동기화한 모델 개수, 동기화 중, "API 키를 설정하면 모델 목록을 동기화합니다", "모델 목록을 동기화하지 못해 마지막으로 받은 목록을 표시합니다", "엔드포인트에서 모델 목록을 동기화하지 못했습니다" 가운데 하나입니다. 엔드포인트가 더 이상 제공하지 않는 모델은 따로 표시합니다. 다른 모델을 골라 저장하기 전까지 요청이 거절되기 때문입니다.

공급자를 연결하면 대화를 열 수 있고, 타일 머리글의 분할 제어로 메인 영역을 최대 4개 타일까지 나눌 수 있습니다. 타일이 무엇을 소유하는지는 [타일로 나뉜 채팅 그룹](../../design/tiled-chat-groups.md)에 정리돼 있습니다.

- 템플릿 문구와 낡은 계획 문구는 그대로 두지 말고 삭제합니다.
